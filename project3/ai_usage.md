# AI Usage

Throughout this project, I used AI as a support tool to guide my learning and help troubleshoot issues.

Overall, AI was most helpful as a debugging and learning tool. Instead of giving me final answers, it helped me:
- break down problems step by step
- understand why errors were happening
- learn how different components (APIs, Flask, HTML/CSS) connect together

## API

During the API stage, I used AI to help me understand how to structure API requests. While I had prior expore to APIs from our in-class example of OpenAI, AI helped me clarify how to connect the two APIs, helped me with how to extract specific data from those APIs, and how to debug issues when responses were empty or incorrectly formatted.

Note: I still wrote and tested the functions myself, but AI helped explain what each part of the response data meant and how to pull the correct information

## Flask Web App

I used AI to understand how to structure routes and hendle POST requests. Also it really helped me with connecting my existing Python helper functions to the web app, which I was struggling with. AI helped a lot with debugging at this stage, especially because the app would not load or was incorrectly running termianl code. For HTML and CSS, I used to AI too, to help me generated a starting layout and styling. This helpde me focus more on understanding how Flask connects to the front end rather than spending excessive time on syntax errors.

## Mapbox map

Lastly, I used AI to help implement the additional feature of the interactive Mapbox map (milestone 3). This was on the flask frontend and for the html/css. AI helped explain how this connection worked and provided a starting structure.
