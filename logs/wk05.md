## What I learned this week

Class focused on iteration and search. We focused on while loop and how it keeps running until a condition becomes false, which is differeent from a for loop that repeats over a number of times. Using for loop is useful for when you know how many times to repeat something, and while loops are better when the loop depends on a changing condition.

Also learned about break & continue. break exits a loop mmediately once a condition is met, and continue skips the current iteration and moves to the next one. 

We also learned looping through strings. We practiced checking whether a word contains certain letters, which introduced the search pattern (using for loops).

## Code I'm proud of (optional)

Basic level code/foundation for building for loop and while loops for reference:

# for loop example
for i in range(5):
    print(i)

# while loop example
count = 0
while count < 5:    # create a while condition. can even be != if u want to run for longer
    print(count)
    count += 1
