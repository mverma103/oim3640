### Chapter 2 - Values and Types, Varibles, Expressions, Statements

Values and Types: int, float, str, bool (use type(x) to check what something is)

Variables: x = 26.2, pi = 3.14159, message = "hello world" as examples (name that refers to a value)
- variables must start with a letter or underscore, can contain letters, numbers, and underscores, cannot use python words, and is case-sensitive (good rule is to use lower-case letters)

Expressions: +, -, *, /, //, %, **

Statements vs expressions: expressions produce a value, statements do something (ex: 2+3 vs x = 5)
