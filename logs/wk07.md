## What I learned this week

This week focused on Chapter 9 which is about lists. A list is basically a sequence like a string, but we can store multiple types of data like strings, numbers, and booleans. We can access elements the same way using indexing.

The difference of lists and strings is that lists are mutable, meaning we can change them directly. With strings, trying to change a character gives a TypeError, but with lists you can just reassign a value (like stocks[2] = 'META').

We also learned about slicing. Slicing returns a new list, not the original one, which becomes important when thinking about copying vs referencing

We also went over list methods like append(), extend(), pop(), and remove(). One important thing is that most of these modify the list in place.

We also learned how lists and strongs connect. split() turns a string into a list, and join() turns a list back into a string. We also use sorted() which returns a new sorted list without changing the original

## Challenges I faced

The most important (and confusing) concept was aliasing. If you do b = a, it does not make a copy, both variables point to the same list. So if you change one, the other changes too. To actually copy a list, you need to use slicing like a[:] or list(a).

It is not very intuitive that assigning one list to another variable doesn't make a copy. I hav eto remind myself to use slicing or list() when I actually want a seperate list.

## has digit
def has_digit(s):
    for c in s:
        if c.isdigit():
            return True
        else:
            return False
print(has_digit('iPhone15'))   # False
print(has_digit('4ever'))      # False
print(has_digit('hello'))      # False

## has lower
def has_lower(s):
    for c in s:
        if 'c'.islower():
            return True
        else:
            return False
print(has_lower('NASA'))     # True
print(has_lower('Python'))   # True
print(has_lower('copilot'))  # True
