In our code, we made routes like /, /hello, /hello/<name>, etc. which showed me how URLs can connect directly to the specific functions. We also learned about render_template() to connect Flask with HTML to make the website feel more strucured.

One thing I thought was cool was using dynamic routes, where part of the URL changes and gets passed into the function. So if someone enters a name or a number in the URL, the app can use that input and generate a different response.
