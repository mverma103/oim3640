## Boolean expressions
Expressions that ealuate to True or False:
x = 5
x == 5 # True (equality)
x != 3 # True (not equal)
x > 10 # False (greater than)
x >= 5 # True (greater than or equal to)

Logical operators combine conditions:
age = 25
age >= 18 and age < 65      # True
age < 18 or age >= 65       # False
not (age < 18)              # True
