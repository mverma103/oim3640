# Session 26 Learning Log

In-Class Gallery Walk Through Presentations

## What I learned this week

This weeks gallery walk was really useful because it showed how different people approached similar technical concepts in completely different ways. Instead of just focusing on code, I got to see how people turned ideas into actual usable products, and just the large variety of topics/apps that could be built!

One thing I noticed was that many of the best projects were not necessarily the most technically complex, but the ones that focused on solving a clear problem and making the user experience simple. A lot of projects also felt very real world oriented, which made them more interesting to interact with.

I also learned that there are many different tools and approaches beyond what we explicitly covered in class. For example, some projects used OCR instead of APIs, while others focused more on UI/UX and presentation rather than backend complexity. This made me realize that there is no single “correct” way to build a project, and that creativity plays a big role.

Also it was not asking peers what AI tools they used to help them code this, receiving answers like Claude, Codex, GitHub Copilot, etc. It was also interesting gaining insights on what was the hardest thing to code or how they leveraged AI to enhance their project more!

## Observations from other projects

Some of the most notable projects I saw included:

- Receipt Splitter App: This allowed users to upload a photo of a receipt, extract all the line items using OCR, and then split the cost across multiple people while adjusting for tax and tip. I thought this was really impressive because it did not rely on APIs and instead used OCR for image-to-text processing, which I had not considered or known of before.
- Resume to Personal Website Tool: This project converted a resume into a personal website that included projects, links, and supporting materials. What stood out was that it was already deployed and felt like a real product, which made it much more impactful.
- Calendar Planner: allowed students to create multiple calendars and show the completion of their tasks. There were many templates but could also create any. 


## Feedback I received

The feedback I received on my equity research stock tool focused mostly on improving usability and presentation rather than the core functionality.

Some key points included:
- Adding a graph of stock price data to make the analysis more visual
- Making valuation outputs more interactive (e.g., hover to explain how calculations are done)
- Breaking down the AI-generated summary into smaller, structured sections instead of one long output
- Creating a homepage that shows a quick overview of each section, with the ability to expand into more detailed analysis
- Adding explanations for each section to make the tool more beginner-friendly
- Improving the formatting of bull/base/bear cases to make them easier to understand visually
- Including an industry overview with competitors and market trends
- Adding a section for similar stocks (ex: NVDA finds AMD, TSMC)
- Making the app more accessible by suggesting popular or trending stocks instead of requiring users to input one
- Potentially adding features like upcoming earnings reports

While this is obviously a lot of feedback, I really appreciated all the unique ideas for where I could take this project! Based on the feedback and what I observed from other projects, I want to shift my focus from just functionality to overall user experience.

The biggest change I want to make is restructuring the interface so that information is easier to navigate. Instead of presenting everything at once, I plan to break the analysis into sections with short summaries and allow users to expand for more detail.

## Takeaway

The biggest takeaway from the gallery walk was that a successful project is not just about having working code, but about how the user interacts with it. Simplicity, clarity, and usability often matter more than complexity, and I want to apply that mindset to improving my own project.
