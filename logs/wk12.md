Building on what we learned from Flask apps last week, one of the biggest concepts was understanding how to run it on a server than can be access through a URL (rather than the app locally on 127.0.0.1)

This was super important because we saw a real example (from our professor) of an API key being exposed and immediately being shut down, which showed us how serious security is in the real world (especially how quick OpenAI was to catch it too!). Using python-dotenv to load keys locally was super important.

Lastly, we learned about deployment of code. We looked at Render and PythonAnywhere and how to push code from GitHub and connect it to a live web service. I learned that these require additional steps to setup, like creating a requirements.txt file and a production server gunicorn.
