## Chapter 2 - Variables and Statements

variable is a name that refers to a value (ex: x = [number])
They can be as long or as short and contain numbers and letters, but a few rules:
- can only have _ as punctuation
- prefer to use lowercase
- cannot start with a number
- cannot be the name of a keyword already in python (ex: class)

We can import features (this chapter uses import math as an example)
math.pi and math.sqrt are features in this example

print function helps us display (can display variables and + them together)

## Debugging

3 main types of errors: syntax, runtime, and semantic error
when running on VSC, the error will tell you what type of error it is (either syntax or runtime)
syntax - incorrect syntax usage
runtime - something goes wrong after running the code
semantic - runs without generating error message, its doing something that you did not intend due to an error (hard to find compared to the others)
