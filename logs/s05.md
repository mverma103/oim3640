### Chapter 3 - functions

Functions are important because they allow you to organize code, reuse code, create complex operations into simple names, and test your program independently, they're super important

print() vs return:
- print() displays on screen
- return gives value back to caller

local vs global variables:
- local variables are created inside a function, isn't defined outside the function (will result in an error)
- global variables are created outside a function, they are accessible everywhere
* golden rule is to prefer local variables; avoid global variables when possible
