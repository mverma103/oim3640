## Mini Project Ideas

While I have many ideas, I think the most applicable to what we have been learning in class about functions, loops, and conditional statements while being the most fun would be an app/game for a casino type of thing.

Even though it might not be the most useful/practical in the real world, I think it's super fun and will help me develop the skills I am currently struggling with in our course material.

## Overview

To start, I would want 3 simple casino like games: a coin flip, a dice game (where you can bet an individual number, or higher/lower), and a roulette like game (bet on red, black, green to start, if time can introduce betting on number group, odd/even, individual numbers, etc.)

## home page

There would be a home page where a user could select multiple tabs using numbers for the game and general menu screen. This would look something like (very rough draft as idk how feasible it is):
Balance: xx
- 1: Coin Flip
- 2: Dice
- 3: Roulette
- 4: Stats (this could be like total P/L, games won, etc.)
- 5: Odds (shows you the betting odds for each game)
- 6: Recent bets (shows you the 5-10 most recent bets and your current balance)
- 7: Quit

## Coin flip

This would be a simple game, using if/else statements to determine if the coin is heads and tails. The user would make a bet, the random coin flip would happen, if the user wins, he gets 1:1 payout on the bet and returns to the menu, if not he loses his balance and returns to the menu

## Dice

A little more complex. The user would choose a betting style, either betting on higher (4-6) or lower (1-3) which is similar to coinflip and 1:1 odds, or betting on an individual number 1-6 (5:1 odds), then user would place bet amount, dice would roll, and payout/loss would be done and go back to home menu

## Roulette

Most complex of the 3. The user again chooses a betting style, either betting on color (red/black for 1:1 odds, green for 35:1), odd/even (1:1 odds), number range (1-12, 13-24, 25-36 for 2:1), and lastly individual number for 35:1 odds. while i am not sure the feasibility of making multiple bets, I do want my best to include as many betting options as I can for the user, to make it as realistic as possible.
