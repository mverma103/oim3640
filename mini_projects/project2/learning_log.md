## What I Did Well

One thing I did well was structuring my code into clear functions. I separated each step of the process into its own function, such as loading files, cleaning text, counting words, and analyzing songs. This made the program much easier to read and debug, which is something I struggled with in the first iteration of project 1.


I also improved a lot with using dictionaries. In the beginning, I only understood them conceptually, but through this project I was able to use them to count word frequencies and actually see how useful they are for storing and analyzing data.

I also like the approach I've been taking of making multiple iterations, with the first version being very simple and just counting words. It allowed me to find early results that there would be lots of issues with punctuation, common words, adlibs, etc. It allowed me to improve the analysis in the second iteration, by removing those issues.
