## Overview

I found this project really interesting because it built directly on my first casino game, but allowed me to go much deeper into how the logic actually works. Compared to Project 1, this version felt much more structured and realistic, especially with features like multiple decks, betting, and strategy decisions. 

The main areas I wanted to improve on for this project were working with lists/dictionaries, managing state across multiple rounds, and building more complex logic using functions. I also wanted to better understand how to simulate real-world systems, which I did through the Monte Carlo simulation.

This project felt like a mix of interactive programming and analytical thinking, since I was not only building the game but also analyzing outcomes through simulation. While it is a game at the end of the day, it feels almos tlike a simulation to help people better learn about blackjack too.

## What I Did Well

One thing I did well was structuring the program into clear, reusable functions. Each part of the game (deck creation, dealing cards, calculating totals, handling turns, settling bets) was separated, which made the code easier to debug and expand. It is a big improvement since the start of the semester when we first learned about functions. It allowed me to iterate further on milestones while keeping it structured.

I also improved a lot with using lists, especially for representing hands and decks. In this project I used them heavily to manage cards, simulate multiple decks, and handle gameplay logic.

Another thing I did well was building multiple iterations of the game. I started with a very basic version (similar to Project 1), then added features like betting, splitting, and multiple rounds, and finally added strategy hints and simulation. This iterative approach helped me identify issues early and continuously improve the project, just like I was able to do for all projects.

I also think the strategy hint system was a strong addition. It required more detailed conditional logic and made the game feel more realistic and educational rather than just interactive.

## What I Plan to Continue for this Project

If I had more time, I would want to improve the user experience further. For example, I could redesign how information is displayed in the terminal to make it feel even more like a real casino interface, possibly using colors or more structured layouts.

I would also be interested in expanding the simulation aspect. Right now, the Monte Carlo simulation uses a simple strategy, but I could compare different strategies (e.g., random play vs. basic strategy) to analyze performance differences.

Ultimately, another idea would be turning this into a web app using Flask, similar to Project 3, which would make it more interactive and accessible, with a much better UI/UX desgin, and feel like a web game!
