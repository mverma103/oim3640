## My Project Proposal

**What I'm building:**  
I am building a Python Blackjack game that lets users play against a dealer, manage a bankroll, receive basic strategy hints, and optionally run a Monte Carlo simulation to test outcomes over many hands.

**Why I chose this:**  
I chose this project because it builds directly on my first casino game project, but allows me to go deeper with better game logic, lists, functions, randomness, and strategy. Blackjack is also a good fit because it combines user interaction with probability, decision-making, and simulation, which makes it both fun and useful for practicing Python.

**Core features:**  
- Deal cards to the player and dealer using a shuffled deck  
- Let the player hit or stand while tracking hand values  
- Handle Blackjack rules such as dealer hitting until 17 and Ace values as 1 or 11  
- Include a bankroll and betting system  
- Provide basic strategy hints for whether the player should hit or stand  
- Add a Monte Carlo simulation mode to run many hands and compare outcomes  

**What I don't know yet:**  
- How to handle Aces cleanly when calculating hand values  
- How to structure the deck and hands using lists  
- How to make the game loop feel smooth across multiple rounds  
- How to design a useful basic strategy hint system  
- How to run and summarize a Monte Carlo simulation clearly
